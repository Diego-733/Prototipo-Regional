Cada hallazgo debe poder rastrearse a una fila de la
[plantilla de registro](plantilla-registro-simulacion.md).

- **Prioridad:** Alta (impide completar una tarea) / Media (genera dudas o errores) / Baja (detalle).
- **Decisión:** Cambiar / Investigar más / No cambiar (indicar motivo).
- **Cambio realizado:** describir el cambio y la versión o commit donde se hizo.
- **Efecto esperado:** qué debería mejorar y cómo se comprobará en la próxima prueba.
